# FHE Core

This is a core project implementation based on FHEVM.

## Requirements

- Node.js >= 14.0.0
- npm >= 6.0.0

## Configuration
Copy `.env.example` to `.env` and fill in the required values.

## Installation and Begin

Install:
```bash
npm install
```

For development:
```bash
npm run dev
```
For production:
```bash
npm run build
npm start
```
